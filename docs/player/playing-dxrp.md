## Joining a server

1. Open s&box and find **DXRP** ([sbox.game/dxura/rp](https://sbox.game/dxura/rp)), or browse servers directly from the in-game server list.
2. Pick a community server and connect. Each server is run independently by its own operators, so rules, economy, and addons can differ between servers.
3. You'll be authenticated automatically with your Steam identity.

Looking for a server to join? Check [dxrp.net](https://dxrp.net) or the [Discord](https://discord.gg/uBwQ2QHP2D) for active communities.

## Getting help

- Questions about a specific server (rules, bans, economy) are handled by that server's own operators/moderators.
- Questions about DXRP itself, bugs, or feature requests belong in the [Discord](https://discord.gg/uBwQ2QHP2D).

## Running your own server
