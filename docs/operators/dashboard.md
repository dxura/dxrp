**Where:** Open **Dashboard** in the portal.

The dashboard is the network-wide status page. It refreshes automatically, so use it for a quick health check before opening a specific server or player.

## What it shows

- **Online Players**: players connected across the network now.
- **Recent Players (24H)** and **Total Players**: recent activity and the network's all-time player count.
- **Global Balance**: the combined player balance and its recent history.
- **Live Overview**: each server's status, player count, peak, uptime, and health.
- **Announcements**: the message shown to players for the selected network.

Select a row in **Live Overview** to open that server in [Servers](/docs/operators/operations/servers).

## Find a player

If your rank can view player profiles, paste a Steam64 player ID into the dashboard shortcut. The portal opens that player's page directly. Use the full [Players](/docs/operators/community/players) tab when you only know a name or need filters.

## Update announcements

Edit the announcement, preview it, and save. The preview uses one of your network's servers, so the portal cannot preview if the network has no server yet.

Announcement editing requires `announcements.edit`. Other dashboard cards are hidden when your rank lacks the permission for their underlying data.

## Before acting on data

Check the network selector in the top-right. Dashboard totals and announcements belong to the selected network, not your account globally.
